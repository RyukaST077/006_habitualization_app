# 2. 背景・目的・ゴール

## 2.1 背景（現状課題）

- 現状：個人の習慣継続には日次記録と可視化が必要だが継続しにくい
- 課題：記録負荷、達成可視化不足、再開のしづらさ
- 影響：継続率低下により習慣化価値が成立しない

## 2.2 目的（Why）

- 目的：個人ユーザーが習慣を無理なく継続できる運用を提供する
- 期待効果（定量）：
  - Retention_7d = 30%
  - Retention_30d = 10%
  - 週平均チェックイン回数 = 6回/週
  - 習慣登録→初回達成率 = 60%

## 2.3 成果物と範囲

- 提供するシステム／機能：
  - Googleログイン + 初回ポリシー同意（利用規約/プライバシー別管理）
  - 習慣作成/編集/アーカイブ/再開
  - 日次チェックイン（同日1回目のみ有効）
  - ストリーク/履歴表示
  - 設定変更（TZ/締め時刻）
  - 退会（60秒以内不可化 + 5分以内完全削除）
  - 匿名KPI集計（DAU/チェックイン等）
- 提供しないもの：
  - ユーザー向け通知、課金、コミュニティ機能
