## 3. API定義
- Method: `GET`
- Path: `/api/policies/current`
- Response:
```json
{
  "terms": { "version": "v1.0", "url": "https://..." },
  "privacy": { "version": "v1.0", "url": "https://..." }
}
```
- Method: `POST`
- Path: `/api/policies/consents`
- Request:
```json
{
  "consents": [
    { "policy_type": "terms", "policy_version": "v1.0" },
    { "policy_type": "privacy", "policy_version": "v1.0" }
  ]
}
```
