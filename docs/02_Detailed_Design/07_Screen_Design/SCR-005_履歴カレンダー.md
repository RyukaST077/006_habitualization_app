# SCR-005 履歴カレンダー

## 1. 画面レイアウト概要
- 構成: 月カレンダー、習慣フィルタ、`archivedを表示` スイッチ。
- トレース: ← [FNC-008](../../01_Project_Design/05_Feature_List.md#L77)

## 2. 画面項目定義
| No | 項目名 | 形式 | 必須 | 初期値 | 入力規則・バリデーション | 備考 |
| -- | -- | -- | -- | -- | -- | -- |
| 1 | 表示年月 | MonthPicker | 〇 | 当月 | YYYY-MM | |
| 2 | 習慣フィルタ | Select | - | 全習慣 | active優先 | |
| 3 | archived表示 | Switch | - | OFF | ON時のみarchived含める | |
| 4 | 日付セル状態 | Cell | - | API値 | 達成/未達成/猶予を色+ラベルで表示 | |

## 3. API定義
- Method: `GET`
- Path: `/api/history/calendar`
- Request:
```json
{
  "year_month": "2026-02",
  "habit_id": null,
  "include_archived": false
}
```
- Response:
```json
{
  "days": [
    {
      "date": "2026-02-11",
      "status": "checked",
      "streak_state": "maintained"
    }
  ]
}
```

## 4. イベント・アクション定義
| イベント | トリガー | 処理概要 | 遷移先 |
| -- | -- | -- | -- |
| 月変更 | Change | カレンダー再取得 | 自画面 |
| フィルタ変更 | Change | 再取得 | 自画面 |
| archived切替 | Toggle | include_archived を変更して再取得 | 自画面 |

## 5. 状態/権限
- Empty: 対象月データなしでもカレンダー枠を表示。
- Error: 通信失敗時は再読込ボタン。

## 6. その他
- 性能: 初期表示P95<=3秒。
