# SCR-003 習慣作成

## 1. 画面レイアウト概要
- 構成: 習慣名入力、表示順入力、保存/キャンセル。
- トレース: ← [FNC-004](../../01_Project_Design/05_Feature_List.md#L73)

## 2. 画面項目定義
| No | 項目名 | 形式 | 必須 | 初期値 | 入力規則・バリデーション | 備考 |
| -- | -- | -- | -- | -- | -- | -- |
| 1 | 習慣名 | Text | 〇 | - | 1〜80文字、前後空白trim | |
| 2 | 表示順 | Number | - | 100 | 1〜9999 | |
| 3 | 保存 | Button | - | - | バリデーション成功時のみ有効 | |

## 3. API定義
- Method: `POST`
- Path: `/api/habits`
- Request:
```json
{
  "name": "朝の散歩",
  "display_order": 100
}
```
- Response:
```json
{
  "habit_id": 1,
  "status": "active"
}
```

## 4. イベント・アクション定義
| イベント | トリガー | 処理概要 | 遷移先 |
| -- | -- | -- | -- |
| 保存押下 | Click | 入力検証、習慣作成API呼び出し | SCR-002 |
| キャンセル | Click | 保存せず戻る | SCR-002 |

## 5. 状態/権限
- Loading: 保存中disabled。
- Error: 入力エラーはフィールド下、システムエラーはトースト。
- 権限制御: ROLE-001のみ。
