# SCR-001 ログイン

## 1. 画面レイアウト概要
- 構成: ロゴ、説明文、`Googleでログイン` ボタン、エラーメッセージ領域。
- 役割: 認証開始のみ。認証後は同意判定へ遷移。
- トレース: ← [FNC-001](../../01_Project_Design/05_Feature_List.md#L70), ← [IF-001](../08_Interface_Design/IF-001_認証セッション確立.md)

## 2. 画面項目定義
| No | 項目名 | 形式 | 必須 | 初期値 | 入力規則・バリデーション | 備考 |
| -- | -- | -- | -- | -- | -- | -- |
| 1 | Googleでログイン | Button | - | - | 多重クリック防止（loading中disabled） | |
| 2 | エラーメッセージ | Alert | - | 非表示 | 認証失敗時のみ表示 | |

## 3. API定義
- Method: `POST`
- Path: `/api/auth/google/start`
- Request:
```json
{
  "redirectTo": "/home"
}
```
- Response:
```json
{
  "auth_url": "https://...",
  "trace_id": "uuid"
}
```

## 4. イベント・アクション定義
| イベント | トリガー | 処理概要 | 遷移先 |
| -- | -- | -- | -- |
| Googleログイン押下 | Click | 認証開始API実行、成功時OAuthへリダイレクト | 外部（Google） |
| 認証成功コールバック | Redirect | セッション確立後、同意判定 | SCR-008 or SCR-002 |
| 認証失敗 | API Error | エラー表示 | 自画面 |

## 5. 状態/権限
- Loading: ボタンdisabled + スピナー表示。
- Error: トースト + インライン表示。
- 権限制御: 未認証のみ表示。認証済みは `/home` へ遷移。

## 6. その他
- 監査:
  - 認証開始/失敗は `LOGIN_START/LOGIN_FAILED`（`FR-001`）。
  - 認証後の同意判定/拒否は callback側で `POLICY_CONSENT_ACCEPT/POLICY_CONSENT_REJECT`（`FR-026`）。
- アクセシビリティ: Enterキーでボタン実行、ボタンに `aria-label` 設定。
