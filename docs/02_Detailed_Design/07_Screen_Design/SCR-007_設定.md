## 2. 画面項目定義
| No | 項目名 | 形式 | 必須 | 初期値 | 入力規則・バリデーション | 備考 |
| -- | -- | -- | -- | -- | -- | -- |
| 1 | タイムゾーン | Select | 〇 | Asia/Tokyo | IANAのみ | `profiles.timezone` |
| 2 | 締め時刻 | Time | 〇 | 03:00 | HH:mm, 00:00〜23:59 | `profiles.day_cutoff_time` |
| 3 | 保存 | Button | - | - | 変更時のみ活性 | |
| 4 | 退会 | DangerButton | - | - | 2段階確認モーダル | |

## 3. API定義
- Method: `GET`
- Path: `/api/settings/profile`
- Method: `PATCH`
- Path: `/api/settings/profile`
- Request:
```json
{
  "timezone": "Asia/Tokyo",
  "day_cutoff_time": "03:00"
}
```
- Response:
```json
{
  "saved": true,
  "effective_from": "2026-02-11T10:00:00Z"
}
```
- Method: `POST`
- Path: `/api/settings/withdrawal`

## 4. イベント・アクション定義
| イベント | トリガー | 処理概要 | 遷移先 |
| -- | -- | -- | -- |
| 保存押下 | Click | 入力検証、設定更新、監査ログ記録 | 自画面 |
| 退会確定 | Click | 退会API実行、セッション破棄 | SCR-001 |

## 5. 状態/権限
- 権限制御: ROLE-001のみ。
- Error: 入力不正はフィールド表示、退会失敗はトースト+再試行案内。
