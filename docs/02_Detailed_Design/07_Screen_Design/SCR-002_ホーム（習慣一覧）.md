- 構成: 習慣カード一覧、当日達成ボタン、取消ボタン、ストリーク表示、導線リンク（作成/編集/履歴/設定）。
- トレース: ← [FNC-005](../../01_Project_Design/05_Feature_List.md#L74), ← [FNC-006](../../01_Project_Design/05_Feature_List.md#L75), ← [FNC-007](../../01_Project_Design/05_Feature_List.md#L76), ← [FNC-008](../../01_Project_Design/05_Feature_List.md#L77)

## 2. 画面項目定義
| No | 項目名 | 形式 | 必須 | 初期値 | 入力規則・バリデーション | 備考 |
| -- | -- | -- | -- | -- | -- | -- |
| 1 | 習慣名 | Text | - | API値 | 80文字以内表示 | `habits.name` |
| 2 | 状態バッジ | Badge | - | active | activeのみ表示 | `habits.status` |
| 3 | 今日達成ボタン | Button | - | 未達成時有効 | 同日2回押下時は冪等成功表示 | |
| 4 | 取消ボタン | Button | - | 当日達成時有効 | 当日外取消不可 | |
| 5 | 現在ストリーク | Text | - | 0 | 計算結果表示 | |
| 6 | 再開導線 | Link | - | 非表示 | archived対象エラー時のみ表示 | SCR-004へ |

## 3. API定義
- Method: `GET`
- Path: `/api/home/habits`
- Request:
```json
{
  "includeArchived": false
}
```
- Response:
```json
{
  "items": [
    {
      "habit_id": 1,
      "name": "朝の散歩",
      "status": "active",
      "is_checked_today": true,
      "streak": 5,
      "log_date": "2026-02-11"
    }
  ],
  "trace_id": "uuid"
}
```
- Method: `POST`
- Path: `/api/checkins`
- Request:
```json
{
  "habit_id": 1
}
```
- Response:
```json
{
  "result": "success",
  "idempotent": false,
  "log_date": "2026-02-11"
}
```
- Method: `DELETE`
- Path: `/api/checkins/{habit_id}?log_date=YYYY-MM-DD`

## 4. イベント・アクション定義
| イベント | トリガー | 処理概要 | 遷移先 |
| -- | -- | -- | -- |
| 画面初期表示 | onLoad | active習慣一覧を取得 | 自画面 |
| 達成押下 | Click | チェックイン登録、カード再描画 | 自画面 |
| 取消押下 | Click | 当日分のみ取消API | 自画面 |
| archivedで達成押下 | Click | 409受信、再開導線を表示 | SCR-004 |

## 5. 状態/権限
- Empty: 習慣0件時は「習慣作成へ」導線を表示。
- Error: 500/通信エラー時はリトライボタンを表示。
- 権限制御: 本人データのみ（RLS + API再検証）。

## 6. その他
- 監査: CHECKIN_CREATE / CHECKIN_CANCEL / CHECKIN_REJECT_ARCHIVED。
- 性能: P95 3.0秒以下（NFR-001）。
