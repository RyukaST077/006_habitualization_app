# IF-001 認証セッション確立

## 1. 概要
- 目的: Google OAuthにより認証を行い、Supabaseセッションを確立する。
- トレース: ← [FNC-001](../../01_Project_Design/05_Feature_List.md#L70), ← [SCR-001](../07_Screen_Design/SCR-001_ログイン.md)

## 2. 接続情報
- 接続先システム: Google OAuth / Supabase Auth。
- 環境: Dev/Stg/Prod。
- Endpoint:
  - `POST /api/auth/google/start`（アプリ）
  - `POST /api/auth/google/callback`（アプリ）
  - Supabase Auth endpoint（`/auth/v1/authorize` 経由）
- Method/Protocol: HTTPS + OAuth2 Authorization Code。
- 認証情報:
  - `SUPABASE_URL`（または `NEXT_PUBLIC_SUPABASE_URL`）
  - `SUPABASE_SERVICE_ROLE_KEY`（同意判定のテーブル参照に使用）
  - `APP_ORIGIN`（callback URL生成）

## 3. リクエスト仕様
### ヘッダー/パラメータ
| 項目名 | 必須 | 説明 | 備考 |
| -- | -- | -- | -- |
| Content-Type | 〇 | application/json | |
| redirectTo | 〇 | 認証成功後の遷移先 | `/home` |

### ボディ
```json
{
  "redirectTo": "/auth/callback"
}
```

## 4. レスポンス仕様
### 正常系
```json
{
  "auth_url": "https://...",
  "trace_id": "uuid",
  "audit_action": "LOGIN_START"
}
```

### エラー系
| Status | Code | 説明 |
| -- | -- | -- |
| 400 | INVALID_REDIRECT | リダイレクト先不正 |
| 401 | AUTH_FAILED | 認証失敗 |
| 500 | AUTH_PROVIDER_ERROR | 外部認証障害 |

## 4.2 Callback API（`POST /api/auth/google/callback`）
### リクエスト
```json
{
  "userId": "uuid",
  "consentState": "unknown"
}
```

- `userId`: OAuth完了後のユーザーID（JWT `sub`）。
- `consentState`: `agreed` / `unknown` / `rejected`。

### レスポンス
```json
{
  "route": "SCR-002"
}
```

- `route` は `SCR-001` / `SCR-002` / `SCR-008`。

## 5. エラー時の挙動・リカバリ
- 認証失敗: ログイン画面へ戻し再試行導線表示。
- プロバイダ障害: トースト表示、30秒後再試行案内。
- 監査: `LOGIN_START/LOGIN_SUCCESS/LOGIN_FAILED` を記録。
- callbackで同意判定に失敗した場合は安全側（未同意）として扱い、`SCR-008` へ誘導する。
