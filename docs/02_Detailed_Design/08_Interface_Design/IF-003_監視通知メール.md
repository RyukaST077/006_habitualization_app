# IF-003 監視通知メール

## 1. 概要
- 目的: 閾値超過時に単一通知先へP1/P2通知を送る。
- トレース: ← [FNC-009](../../01_Project_Design/05_Feature_List.md#L78), ← [AC-018](../../01_Project_Design/01_Requirements.md#L208)

## 2. 接続情報
- 接続先システム: Supabase Edge Functions（閾値判定 + 通知送信）。
- Endpoint/Host: `https://<project-ref>.functions.supabase.co/ops-alert-dispatcher`。
- Method/Protocol: HTTPS Webhook または SMTP。
- 認証情報: 通知先メール、Webhook secret。

## 3. リクエスト仕様
### ヘッダー/パラメータ
| 項目名 | 必須 | 説明 | 備考 |
| -- | -- | -- | -- |
| Content-Type | 〇 | application/json | |
| X-Alert-Signature | 〇 | 署名検証 | webhook時 |

### ボディ
```json
{
  "alert_level": "P1",
  "alert_type": "five_xx_rate",
  "threshold_rule": "5m_5xx_rate_gt_5pct",
  "observed_value": 6.2,
  "window_start_at": "2026-02-11T10:00:00Z",
  "window_end_at": "2026-02-11T10:05:00Z"
}
```

## 4. レスポンス仕様
### 正常系
```json
{
  "accepted": true,
  "notification_id": "alt_12345"
}
```

### エラー系
| Status | Code | 説明 |
| -- | -- | -- |
| 400 | INVALID_ALERT_PAYLOAD | 項目不足 |
| 401 | INVALID_SIGNATURE | 署名不正 |
| 503 | NOTIFICATION_UNAVAILABLE | 通知基盤障害 |

## 5. エラー時の挙動・リカバリ
- 送信失敗時は3回まで指数バックオフ再送。
- 再送失敗時は `monitoring_alert_events.notification_status='failed'` に更新し、運用者が手動再送。
- P2通知は既定無効、有効化時のみ送信対象。

## 6. 実装確定が必要な項目
- なし（MVPはEdge Functions実装で確定）。
